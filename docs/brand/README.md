# Brand files

`banner-light.svg` and `banner-dark.svg` are the README banner (1280 × 320).
They are generated, together with the rest of the Loomux brand, by
`docs/brand/generate.py` in [loomux/web](https://github.com/loomux/web),
whose `docs/brand.md` is the brand guideline. Change them there and copy
the outputs here; don't edit them by hand.
