# Target-provider capability (LOOM-178 PR 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A plugin that declares `targets.*` can create machines on demand, and Loomux turns each into an
ordinary managed remote target: generated SSH key in, host key generated by the host and pinned before the
machine exists, `/data/work` as the workspace root, lifecycle (start/stop/recreate/destroy) and reconcile
owned by the host, all through `/api/v1/targets`. No real plugin yet: the fake grows an in-memory `targets.*`.

**Architecture:** `plugins/protocol` gains the `targets.*` vocabulary and `plugins/sdk` a `TargetProvider`
interface; `providers/` is the host side (the `Manager` of design §1.9: rows first, idempotent create,
reconcile table, orphans, cascade delete) over `plugins.Manager`; the registry gains `environments`
(`00029`) and the vault a `target_id` scope (`00030`); the API gains the target additions of design §5; the
router sees `CreatedBy`/`Ephemeral` and starts a stopped machine before dispatching to it.

**Tech Stack:** Go 1.27 stdlib, `golang.org/x/crypto/ssh` (+ `knownhosts`) for key material, the existing
store, metrics and API conventions.

**Spec:** `docs/design/target-providers.md` §1.3 (targets.* methods), §1.9, §2, §5 "Targets" /
"Credentials" / "Attach-info", §7, §12. Review leftovers from #343 go first.

## Global Constraints

- API v1 additions only (`go test ./api -run TestAPIv1Contract -update`); errors `{error, code}`.
- The host validates everything a plugin returns: `Address.Host` must pass the managed-mode host grammar
  (`targets.ValidManagedHost` or equivalent), ports 1–65535, statuses from the fixed list, strings bounded.
- Secrets (the managed private key, the machine's host private key, vault values) never in a response or
  log; the host private key is AES-GCM under the master key, AAD `environment:<id>`.
- Object ids: `lx-<id>` with id = 10 lowercase base32 chars from `crypto/rand`; user text never in names.
- Created machines are `kind: remote`, `ssh_mode: managed`, user `agent`, port from the plugin, pin from the
  generated host key, `workspace_root: /data/work`, `ssh_proxy` per the plugin's `targets.describe`.
- Bounds: create job 10 min; reconcile every `LOOMUX_TARGET_PROBE_INTERVAL`; orphan TTL 24 h.
- Changelog fragment `changes/loom-178-providers-capability.md`.

## Review Focus

1. A plugin returning an address like `-oProxyCommand=x` or `host;id`: refused before any target row is
   written (Task 6 `TestCreateRefusesBadAddress`).
2. loomuxd restarts while a machine is `creating`: startup resumes `targets.create` with the same id and
   the machine comes up once (Task 6 `TestReconcileResumesCreating`).
3. `DELETE /targets/{id}` on a created machine while a task runs there: 409, nothing destroyed (Task 7).
4. The plugin is disabled: lifecycle routes answer 409 "plugin disabled", dispatch to the machine still works
   because it's an SSH target (Task 7/8).
5. A vault credential scoped to a target reaches an agent on that target and no other (Task 5/8).

### Task 1: Protocol and SDK: `targets.*`

**Files:** `plugins/protocol/targets.go`, `plugins/sdk/sdk.go` (dispatch), `plugins/sdk/sdk_test.go`

```go
package protocol
const (
    MethodTargetsDescribe = "targets.describe"; MethodTargetsCreate = "targets.create"; MethodTargetsGet = "targets.get"
    MethodTargetsList = "targets.list"; MethodTargetsStart = "targets.start"; MethodTargetsStop = "targets.stop"
    MethodTargetsRecreate = "targets.recreate"; MethodTargetsDestroy = "targets.destroy"; MethodTargetsHealth = "targets.health"
    MethodTargetsAttachCommands = "targets.attach_commands"
)
type Size struct { Name, CPU, Memory, Disk string }                       // json snake_case
type TargetsInfo struct { Sizes []Size; PersistentDefault bool; EgressOptions []string; Image string; MaxEnvironments int; Environments int; AddressTemplate string; SSHProxy string /* "none" | "default" */; User string /* "agent" */; Port int }
type SSHBootstrap struct { AuthorizedKey string; HostPrivateKey string; HostPublicKey string; Port int }
type EnvironmentSpec struct { ID, TargetID, Name, Size string; Persistent bool; Egress, Image string; SSH SSHBootstrap; Labels map[string]string }
type Address struct { Host string; Port int; Proxy string }
type Environment struct { ID, Status, Reason string; Address Address; ImageDigest, Size string; Persistent bool; Egress string; CreatedAt time.Time }
// Status values: creating, starting, running, stopped, recreating, destroying, lost, error
type EnvironmentHealth struct { Status, Reason string; Restarts int; ImageDigest string }
type AttachCommand struct { Via, Command string }
type IDParams struct { ID string }; type RecreateParams struct { ID string; Spec EnvironmentSpec }; type AttachParams struct { ID, Session string }
```

`sdk.TargetProvider` interface (Describe/Create/Get/List/Start/Stop/Recreate/Destroy/Health/AttachCommands
with those types); `sdk.Handler(p, extra)` dispatches `targets.*` to it when `p` implements it, else
`method_not_found`. Tests: dispatch table, params decoding, an SDK plugin without the interface answers
`method_not_found`. Commit.

### Task 2: Fake plugin's in-memory machines; plugintest targets suite

**Files:** `plugins/fake/fake.go`, `plugins/fake/plugin.json` (capabilities: create, stop_start, recreate,
persistent, ephemeral, attach_commands; settings `targets_mode` enum [ok, create_fails, vanish, slow_start],
`address_domain` default `fake.invalid`), `plugins/fake/fake_test.go`, `plugins/plugintest/targets.go`,
`plugins/plugintest/plugintest_test.go`

The fake keeps `map[id]*machine` guarded by a mutex: `create` idempotent, status `starting` for the first
`get` then `running` (slow_start: three gets); address `lx-<id>.<address_domain>:2222`, proxy `none`;
`stop`/`start`/`recreate`/`destroy` (idempotent, 404 after destroy on get); `list` filtered by
`labels["loomux.io/instance"]`; `vanish`: machines disappear 1 s after running; `create_fails`: `quota`
error; `attach_commands` returns `[{via: "fake", command: "fake attach <id> <session>"}]`. The plugintest
targets suite (`RunTargets`, included by `Run` when the manifest declares `targets.create`): describe
well-formed (sizes non-empty, port 1–65535, user non-empty); create twice same id → same environment;
get/list (list contains it, filtered by instance); stop/start when declared; recreate; health; attach
commands within the grammar (no control chars, ≤ 512 bytes); destroy twice → nil then get → `not_found`.
Commit.

### Task 5: Host-side `providers` package

**Files:** `providers/providers.go` (types, errors), `providers/keys.go` (managed key via
`targets.GenerateSSHKey` + store, origin target; host key pair `ed25519` → OpenSSH PEM + authorized line;

`providers/manager.go`, `providers/reconcile.go`, `providers/manager_test.go` (against the fake through a
real `plugins.Manager`), `providers/README.md`

```go
type Manager struct { store registry.Store; plugins *plugins.Manager; probe func(ctx, targetID string) error; logger; met }
type CreateRequest struct { Target registry.Target /* name, policy, permission_mode from the API */; PluginID, Size string; Persistent *bool; Egress string }
func (m *Manager) Create(ctx, CreateRequest) (*registry.Target, *registry.Environment, error)   // rows first, then a bg job (10 min) runs plugin create → poll get → running → probe
func (m *Manager) Get(ctx, targetID) (*registry.Environment, error)
func (m *Manager) Start/Stop/Recreate(ctx, targetID) error; Destroy(ctx, targetID) error   // 409-class errors: ErrTaskActive (via a TaskChecker func), ErrPluginUnavailable, ErrNotCreated, ErrEphemeralStop, ErrCapabilityMissing
func (m *Manager) DeleteTarget(ctx, targetID) error     // the cascade of design §5: refuse while tasks mid-turn; workspaces+tasks, target-scoped credentials, destroy, key, rows
func (m *Manager) EnsureRunning(ctx, targetID) error   // start a stopped machine and wait ready (bounded); for the router
func (m *Manager) Reconcile(ctx) ; RunReconcile(ctx, interval)   // the table of §1.9 + orphans (24 h)
func (m *Manager) MachineCount(ctx, pluginID) (int, error); UninstallMachines(ctx, pluginID, mode) error   // wired into plugins.Manager
func (m *Manager) AttachCommands(ctx, targetID, session) ([]protocol.AttachCommand, error)
```

`plugins.Manager` gains `Call(ctx, id, method, params, result) error` (refusing a method whose capability
the installed manifest lacks), `Capabilities(ctx, id)`, `TargetsInfo(ctx, id)`, and `OnNotify` for
`targets.changed` (a hint: Reconcile that one id sooner). Tests: create end to end (rows, generated key,
pinned host key `[lx-x.fake.invalid]:2222 ssh-ed25519 …`, target fields), idempotent resume
(`TestReconcileResumesCreating`), bad address refused, stop/start/recreate/destroy, lost ephemeral →
workspaces archived, persistent gone → started again, orphan destroyed after TTL (clock injectable),
cascade delete, uninstall keep → `detached`, destroy → machines gone, `EnsureRunning`. Commit.
