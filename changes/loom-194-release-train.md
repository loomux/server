### Changed

- Every image is published per server release from one run (LOOM-194): `ghcr.io/loomux/server`, `plugin-kubernetes` and `plugin-docker` each get `:X.Y.Z`, `:sha-<short>` and `:main` (the server keeps its bare `:<short>` for now), pushed together only once every build and test job passed, and the GitHub release names each image's `tag@digest`. A version or sha tag is never re-pushed: a re-run of the same commit reuses what exists, and a tag from another commit fails the run. `ghcr.io/loomux/agent` is rebuilt and published only when `deploy/agent` changed; otherwise the release pins the current image. The kind and docker end-to-end tests run when plugin code changed. A run without a version (a merge a newer release already covers, a plain rebuild) no longer moves `:main`.
