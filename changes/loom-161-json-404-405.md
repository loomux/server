### Fixed

- An `/api/v1` path no route matches answers `404 {error, code:
  "not_found"}`, and a method its routes don't take `405 {error, code:
  "method_not_allowed"}` with `Allow`, like every other API error
  (LOOM-161). Both were plain text.

### Added

- Error code `method_not_allowed`, the default for a `405`.
