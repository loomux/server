Loomux server

This image was built without a web client bundle.

You are seeing the placeholder from deploy/web-placeholder/, not the loomux/web Vite build. The JSON API under /api/v1/ is fully functional; only the browser UI is missing.

To build an image with the real UI, point the WEB_DIST build argument at a directory in the build context holding loomux/web's dist/ output:

docker build --build-arg WEB_DIST=.web-dist -t ghcr.io/loomux/server .

See docs/deploy/container.md for the full rationale and for how CI materialises that directory.
